# Portfolio

Personal portfolio of Yash — B.Tech CS & AI student at Newton School of Technology × Rishihood University.

*Eat. Code. Repeat.*

A single-page site, `index.html`: a 3D camera flies through a scroll-driven journey (ASCII hero, project gallery, city dive, contact alley). It is built with plain HTML/CSS/JS and Three.js from a CDN, with no build step.

## Run locally
```bash
python3 -m http.server 5173
```
Then open http://localhost:5173.

## Deploy
Import this repo in Vercel. Framework preset: **Other**. No build command is needed.
